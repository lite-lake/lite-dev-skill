# Invariants

The canonical invariants ship inside the skill, so an installed copy is
self-contained:

- [skills/lite-dev/references/invariants.md](../skills/lite-dev/references/invariants.md)

There is deliberately no second copy. This file exists so people browsing the
repository from the root have an entry point. Nothing is published before 1.0.0,
so the invariants may change freely until then; from 1.0.0 a change is breaking.
